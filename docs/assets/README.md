# README / 官网素材占位说明

此目录用于后续 README、官网、Release 页面或 GUI 文档截图素材。

当前没有提交真实截图或真实结果文件，只保留占位说明。

## 允许的素材

- CLI smoke test 截图：必须显示私钥隐藏。
- 命中结果示例图：地址使用 `Txxxxxxxxxxxxxxxxxxxxxxxxxxxxx8888` 这类占位。
- GUI 草图 / wireframe：明确标注为 mockup。
- 安全提示卡片：强调“私钥就是资产控制权”。

## 禁止的素材

- 真实私钥。
- 真实命中结果 CSV。
- bot token、API key、`.env` 内容。
- 看起来像真实 64 位十六进制私钥的示例字符串。
- 未脱敏的终端历史、用户名、云盘路径、聊天窗口。

## 建议文件命名

- `cli-smoke-private-key-hidden.png`
- `cli-match-placeholder.png`
- `gui-wireframe-placeholder.png`
- `security-banner.png`

提交素材前请先人工审查并确认不含敏感信息。
