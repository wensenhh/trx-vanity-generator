## 3. 功能模块文案

### 多种靓号规则

- 7 连尾：例如结尾 7 个 8。
- 8 连尾：更稀有，也更难。
- 自定义尾号：例如 5201314。
- 顺子尾号：例如 1234567。
- 包含字符：地址中包含指定片段。
- T 后前缀：TRON 地址固定以 T 开头，可匹配 T 后面的内容。

### 本地离线生成

地址和私钥在本机生成。工具不需要把私钥上传到服务器。你应当在可信电脑上运行，并谨慎保管终端日志、结果文件和备份。

### 默认保护私钥

默认不在终端显示私钥，也不在输出文件写入私钥。只有显式开启高风险参数时，才会显示或明文导出私钥。

### CPU / GPU 两种路径

CPU 模式更容易验证环境；GPU 模式通过 OpenCL 使用显卡 / Apple Silicon GPU，但实际速度受设备、驱动、batch size 和实现状态影响。

## 4. 快速开始模块

```bash
# CPU smoke test
./trx_vanity prefix T --max-attempts 64 -t 1

# 7 连尾
./trx_vanity consecutive 8 7 -t 8 -v

# 自定义尾号
./trx_vanity suffix 5201314 -t 8 -v

# GPU 小测试
./trx_vanity prefix T --gpu --batch-size 64 --batches 1

# GPU 搜索 7 连尾
./trx_vanity consecutive 8 7 --gpu --batch-size 65536 -v
```

提示文案：当前是 CLI alpha；普通用户的一键安装体验正在路线图中。

## 7. 安全文案组件

### 短版

私钥就是资产控制权。地址可以公开，私钥绝不能公开。

### 中版

TRX Vanity Generator 默认隐藏私钥，也不会默认把私钥写入结果文件。如果你显式开启私钥显示或明文导出，请只在可信离线环境中操作，并加密保存结果。

### 长版

任何拿到私钥的人都可以控制对应 TRON 地址中的资产。请不要把私钥发送到 Telegram、微信、GitHub、网盘、邮箱、截图同步相册或不可信网站。高价值地址建议使用离线专用环境生成，先用小额资产验证，再进行正式使用。

## 9. FAQ 文案

**这个工具安全吗？**
它的设计目标是本地生成、默认隐藏私钥。但安全也取决于你的电脑、下载来源、日志、结果文件和备份方式。

**可以承诺多久找到 8 连尾吗？**
不能。靓号搜索是概率事件，只能估算，无法承诺。

**为什么现在没有下载按钮？**
当前只有源码 CLI alpha。正式 GUI 和安装包还在路线图中。

**我能把截图发给客服或群友吗？**
只能发脱敏截图。不要发私钥、不要发完整结果文件、不要发 `.env` 或任何 token。
